# Launch Playbook

WANT2VIEW CLI is built to spread through useful workflows, not hype alone.

## Positioning

One-line:

> Open-source CLI that gives Codex, Claude, and terminal agents real content research evidence.

Short version:

> WANT2VIEW CLI turns demo data, CSV/JSON imports, public catalog samples, and WANT2VIEW Cloud runs into agent-ready research packs. The free repo is useful immediately; the paid product unlocks deeper catalog data, private projects, managed social connectors, scheduled refreshes, and custom research.

## Demo Script

```bash
npx want2view codex "ai video ads"
```

Then open:

```text
.want2view/exports/<pack_id>/summary.md
.want2view/exports/<pack_id>/codex_tasks.md
```

## Distribution Ideas

- Pin the GitHub repo on the founder profile.
- Add the CLI block above the public catalog on want2view.com.
- Record a 45-second video: terminal command, generated pack, Codex reading the pack.
- Post on X/LinkedIn: "We open-sourced the terminal bridge for AI content research."
- Publish a short technical post: "How to give AI agents a content research source of truth."
- Invite agencies to request managed connectors or custom research.

## Conversion Path

1. User runs the free CLI.
2. User sees limited public catalog data.
3. User needs their own projects or deeper catalog data.
4. User creates a WANT2VIEW account.
5. User gets API access or orders custom research.
6. User upgrades to managed connectors and scheduled refreshes.
